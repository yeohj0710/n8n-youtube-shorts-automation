건강장수비결 완성 이미지 넣는 곳

1. 완성한 PNG, JPG, JPEG 또는 WebP 이미지를 이 폴더에 바로 넣습니다.
   파일명 앞에 번호를 붙이세요: 07_아침 산책 시간대 순위.png
2. 같은 번호로 문안을 `캡션` 폴더에 넣습니다: 캡션\07_아침 산책 시간대 순위.caption.txt
   형식은 `캡션\README.txt`에 있습니다.
3. 로컬 n8n에서 `건강장수비결 - 완성 이미지 기반 쇼츠` 회로를 엽니다.
4. Execute Workflow를 한 번 누르면 이미지 1개를 무작위로 처리합니다.

회로가 캡션 파일에서 YouTube 제목, 본문, 태그, 고정 댓글을 만듭니다. 캡션이 없으면
GPT-5.2가 이미지를 읽어서 만드는데, 못 읽은 항목이 조용히 빠지므로 캡션을 두는 쪽이
정확합니다. 이어서 BGM 생성, 5초 MP4 렌더링, 공개 업로드, 댓글 작성을 처리합니다.
정상 게시된 이미지는 `사용완료`로 이동합니다.

세로 쇼츠(9:16)만 처리합니다. 이미지 크기를 읽어서 판정하므로 4:5 같은 다른 비율을
넣으면 건너뜁니다. 파일명에 `인스타`나 `4x5`가 들어가면 무조건 제외됩니다.

지원 형식: .png, .jpg, .jpeg, .webp
최대 파일 크기: 50MB

실행 중인 이미지는 `처리중`에 있습니다. 오류가 나면 이미지가 `처리중`에 남을 수 있습니다. 실행이 완전히 끝난 것을 확인한 뒤 원래 폴더로 직접 옮기면 다시 처리할 수 있습니다. 2시간이 지난 처리중 이미지는 다음 실행 때 자동으로 원래 폴더에 복구됩니다.

주의: 회로를 실행하면 KIE 비용이 발생하고 YouTube에 공개 영상이 게시됩니다. 회로를 가져오거나 열기만 해서는 실행되지 않습니다.
