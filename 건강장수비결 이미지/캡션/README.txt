건강장수비결 카드 문안 넣는 곳

여기에 캡션 파일을 두면 회로가 유튜브 제목·설명·태그·고정 댓글을 이 원문에서
그대로 만듭니다. 파일이 없으면 이미지를 GPT-5.2 vision이 읽어서 문안을 만드는데,
못 읽은 항목이 조용히 빠지므로 캡션을 두는 쪽이 정확합니다.

파일명: 이미지와 같은 번호 접두어 + `.caption.txt`
  이미지  →  07_아침 산책 시간대 순위.png
  캡션    →  07_아침 산책 시간대 순위.caption.txt

접두어 숫자만 맞으면 뒤 제목은 달라도 됩니다.

형식 (첫 줄이 제목, `기준:` 한 줄, 그 다음 항목들):

  아침 산책 시간대 순위

  기준: 관절 부담과 혈압 변동을 함께 본 순서

  1. 해 뜬 뒤 한 시간 (1위)
  → 기온이 올라 관절이 덜 뻣뻣하고 혈압도 안정적이에요
  ⚠ 겨울에는 조금 더 늦게 나가세요

  2. 점심 먹고 30분 뒤 (2위)
  → 혈당이 오르는 시간과 겹쳐 걷기 효과가 좋아요

  ──────────
  이 아래 줄은 문안에 들어가지 않습니다. 저장·팔로우 유도나 면책 문구를 적어 두세요.

항목 줄 규칙:
  `N. 이름 (1위)`      → 순위형. 설명 앞에 `1위 이름` 으로 붙습니다.
  `N. [S] 이름`        → 등급형. `[S] 이름` 으로 붙습니다.
  `N. 이름 (추천)`     → 우리말 등급이나 수치. `이름 (추천)` 으로 붙습니다.
  `N. 이름`            → 라벨 없음. 이름만 나옵니다.
  `→ 설명`             → 없어도 됩니다. 이름 자체가 내용인 카드도 있습니다.
  `⚠ 주의`             → 있으면 `(주의: ...)` 로 뒤에 붙습니다.

항목은 2개 이상이어야 하고, 등급 이름은 적은 그대로 나갑니다(S를 A로 바꾸지 않음).
마무리 줄은 회로가 붙입니다: "건강하게 나이 드는 습관을 매일 하나씩 전해 드려요.
구독해 두시면 놓치지 않고 받아보실 수 있어요." 캡션에 따로 쓰지 않아도 됩니다.
